If Windows warns you

HenkerDPI is not code-signed, so SmartScreen may show "Windows protected your PC" the first time you run it. Choose More info → Run anyway. Some antivirus engines flag DPI-bypass tools by category as well — it is a false positive. Every release publishes its SHA-256, and the full source is public if you would rather build it yourself.

Prefer no installer? Download the portable version and run it as administrator.
