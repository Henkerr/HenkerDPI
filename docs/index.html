VPN'siz DPI bypass — Windows

Engellenen sitelere VPN kullanmadan eriş. Trafiğin dışarıdaki hiçbir sunucudan geçmez, bu yüzden hız kaybı yok denecek kadar azdır.

⬇  İndir

Windows 10/11 (64-bit) · ~29 MB · tek dosya kurulum

Kurulum

  1. İndir'e bas, dosya inince çift tıkla.
  2. Windows yönetici izni sorar → Evet.
  3. Kurulum biter, uygulama açılır. Güç düğmesine bas, korumaya başlar.
Windows bir uyarı gösterirse normal. Uygulama dijital olarak imzalanmadığı için ilk çalıştırmada "Windows bilgisayarınızı korudu" ekranı çıkabilir. Ek bilgi → Yine de çalıştır deyip devam et. Bazı antivirüsler de DPI bypass araçlarını yanlışlıkla şüpheli işaretler.

Kurulum istemiyorsan taşınabilir sürümü indirebilirsin (yönetici olarak çalıştırman gerekir). Kurduktan sonra yeni sürümler kendiliğinden gelir, bir daha indirme yapmazsın.
